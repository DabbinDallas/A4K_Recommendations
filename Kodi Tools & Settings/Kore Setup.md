# ***Kore (Official Kodi Remote for Android)*** ▶️
## This an app based remote made by the developers of Kodi, Team Kodi. Some of the features include: Kodi-wide navigation, media controls (including lock screen widget support), phone keyboard and voice typing support, currently playing metadata, changing subtitles and audio streams, volume control with hardware keys, and more. There is also an [official Kodi remote for iOS](https://kodi.wiki/view/Official_Kodi_Remote/iOS) which works very similar but has a different UI, I don't have an Iphone so I wont be adding a tutorial for it on this page.
