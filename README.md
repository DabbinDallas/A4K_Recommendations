## External Scraper Modules
Red Light, The Gears and Umbrella require external scraper modules to function so if you are getting an error message popup in either of those addons that says "No External Providers Enabled" (Red Light and The Gears) OR "No Stream Available" (Umbrella) then you most likely havent enabled and authorized an external provider for those addons to use. ***To install one of the popular scraper modules follow this [LINK](https://github.com/DabbinDallas/A4K_Recommendations/blob/main/External%20Scraper%20Modules.md) and then go back to the recommended addons [L I N K](https://github.com/DabbinDallas/A4K_Recommendations/blob/main/Recommended%20Add-ons.md) and look for the [!NOTE] section of the install guide to learn how to enable it in your addon.***

## Kodi Default Skin Setup
The default skin for Kodi (Estuary) is catered towards using Kodi for local content, as such there's a ton of menus for different media that when using Kodi for third-party addons is irrelevant and make navigating to your addons a bit clunky. Even if you go about downloading a skin from the Kodi addon repository or third-party repositories, you'll find them setup the same way for the most part. So i decided to write a guide in order to teach people how to navigate to the skin settings, customize specifically for use with third-party addons, and learn about what other customization options are present in the settings menu. I also intend the guide to be a jumping off point to be able to navigate to and through the settings for different skins, as i will not be making a guide for other skins on this github. ***You can access the guide for this by clicking on the "Kodi Tools & Settings" folder at the top of this page and clicking on "Kodi Default Skin Setup.md" or by clicking on this [L I N K](https://github.com/DabbinDallas/A4K_Recommendations/blob/main/Kodi%20Tools%20%26%20Settings/Kodi%20Default%20Skin%20Setup.md).*** 

## Kore (Official Kodi Remote) Setup
There's a very useful remote app for use with Kodi that can be installed and setup on Android phones (there is also a iOS app, the steps to set it up are very similar but i dont have an iphone to show the whole process). I highly recommend trying to set it up, especially if you use Kodi on an Android box/tablet/phone, as there are many great features that I go into on the setup page and it's let you have more control of Kodi from your couch/bed. ***You can access the guide for this by clicking on the "Kodi Tools & Settings" folder at the top of this page and clicking on "Kore Setup.md" or by clicking on this [L I N K](https://github.com/DabbinDallas/A4K_Recommendations/blob/main/Kodi%20Tools%20%26%20Settings/Kore%20Setup.md).***

## Language Setup
Alot of torrents that are uploaded on the sites that addons scrape end up playing in languages other than English by default. Instead of having to go into the player settings to change this everytime, you can change it Kodi-wide so it'll effect every addon that you use. ***You can access the guide for this by clicking on the "Kodi Tools & Settings" folder at the top of this page and clicking on "Language Setup.md" or by clicking on this [L I N K](https://github.com/DabbinDallas/A4K_Recommendations/blob/main/Kodi%20Tools%20%26%20Settings/Language%20Setup.md).***

## Installing the error log uploader and getting a clean logfile
Rule #7 on the A4K Subreddit requires you to provide as much information as possible to help make troubleshooting easier for the people who actually know how to help/fix errors that happen in Kodi and its respective addons. One of those bits of information thats really helpful for troubleshooting is an error log. Kodi by itself will not provide you with an easy way to access this error log but theres a specific addon that will upload an error log to a website so you can copy and paste it into your post (certain addons have a built in version of this but I felt it easier to provide a all-in-one solution instead). So i wrote a guide (with pictures) on how to obtain this addon and how to setup for a clean error log to make things easier for the people who know how to troubleshoot. ***You can access the guide for this by clicking on the "Kodi Tools & Settings" folder at the top of this page and clicking on "Getting A Clean Logfile.md" or by clicking on this [L I N K](https://github.com/DabbinDallas/A4K_Recommendations/blob/main/Kodi%20Tools%20%26%20Settings/Getting%20A%20Clean%20Logfile.md).***
